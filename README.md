# Demo CRM

Статичний знімок CRM для інтернет-магазину: огляд роботи, замовлення, клієнти й сегменти, каталог, платежі, виручка, задачі, акції.

- Усі дані вигадані: клініки, імена, телефони, пошта, товари й бренди.
- Це знімок сторінок: навігація, розділи й картки працюють, а пошук, фільтри, форми та зміна статусів доступні лише в живій версії CRM.
- Сторінка закрита від індексації пошуковими системами.

Знімок згенеровано з CRM скриптами `scripts/demo/` (демо-сид і збирач знімка) на порожній демо-базі.
